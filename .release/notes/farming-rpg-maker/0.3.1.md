# Farming RPG Maker 0.3.1

The first release since 0.2.0. The full list is in
[CHANGELOG.md](https://github.com/jxburros/farm-game-engine-native/blob/v0.3.1/CHANGELOG.md#031).

## Highlights

- **Exported games draw on the GPU** (Vulkan, DirectX 12, Metal), switching to
  the CPU renderer when no hardware GPU works or the device is lost.
- **Music and ambience** out of the box, composed and synthesized by the engine,
  plus more minigames.
- **Web demo export**: Export Game can make a browser demo ready for an itch.io
  page, running the same WebAssembly player as the web editor.
- **Play Mode runs the exported cartridge**, exactly what Export Game ships.
- **The game interface in Spanish** and a more readable font; the editor has a
  welcome tour, a built-in Creator Guide (F1) and keyboard shortcuts.
- **Map placement tools** for items, gathering nodes, machines, NPCs and animals.
- **Exported games pause in the background**, and **F12 saves a screenshot**.
- **Editor data safety**: edits that exist only in memory are no longer lost
  when a save fails.
- **Safer pack plugins and a sturdier world**: plugins declare what they may
  change, and doors, warps, tile grids and saves are repaired or bounded instead
  of breaking the game.
- **Safer releases**: releases come only from a CI-green commit on `main`, are
  verified as complete drafts with `SHA256SUMS` and build provenance, and a
  published version is never overwritten.
