# Farming RPG Maker 0.3.1-dev

## Changes

- Exported games pause when their window (or the web demo's tab) loses focus during play. Settings → Display → "Pause when the game is in the background" turns it off; the editor's Play Mode keeps running.
- F12 in the desktop game saves a screenshot as a PNG in the game's `screenshots` folder beside its saves, and a toast says where.
