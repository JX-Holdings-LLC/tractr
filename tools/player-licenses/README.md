# Player license notices

`THIRD-PARTY.txt` covers desktop players and the editor's Rust engine on
Windows, Linux and macOS. `THIRD-PARTY-web.txt` covers the browser player,
including wasm-bindgen and js-sys. Each template ships its matching file as
`THIRD-PARTY.txt`; Export Game copies it to `licenses/THIRD-PARTY.txt`.
The editor also ships the desktop notices as `licenses/THIRD-PARTY-rust.txt`.

`generate.sh` writes both files:

1. [cargo-about](https://github.com/EmbarkStudios/cargo-about) lists the Rust
   crates in `farm-player`'s dependency graph for Windows, Linux and both Mac
   architectures (`about.toml`), and separately in `farm-wasm` for wasm32
   (`about-web.toml`). Both use `about.hbs` for their license texts;
2. it appends what cargo-about can't see: the Inter and Atkinson Hyperlegible
   fonts (`assets/fonts`), the plugin sandbox guest that `farm-plugins` embeds
   (quickjs-ng, rquickjs-sys, wasi-libc with musl and cloudlibc; texts in
   `plugin-guest/`), and the player's own licenses (`LICENSE`, and `LICENSE-MIT` for the plugin guest).

```sh
cargo install cargo-about --locked --features cli   # CI uses 0.9.2
tools/player-licenses/generate.sh                   # rewrite both notice files
tools/player-licenses/generate.sh --check           # fail when it is out of date (CI)
```

Run it after changing `farm-player` or `farm-wasm` dependencies, the embedded fonts, or the
plugin guest's dependencies, and commit the result. The editor's own .NET
notices are generated by [`tools/editor-licenses`](../editor-licenses/generate.mjs).
